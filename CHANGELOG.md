# Changelog

All notable changes to this package will be documented in this file.

## [1.0.0] - 2026-08-25
### Added
- Standardized package structure for WASD Mobile Studio and UPM.
- Integrated `AppLovinAdsAdapter` implementing `WASD.Core.Services.Ads.IAdsService`.
- Automatic Impression-Level Ad Revenue integration with `WASD.Core.Services.Tracking.TrackingService`.
- Editor window `AppLovinEditorWindow` for Ad Units config, Scoped Registries setup and Android AAR management.
- Added `link.xml` for IL2CPP stripping safety.
