# Changelog

All notable changes to this package will be documented in this file.

## [1.0.0] - 2026-08-25
### Added
- Standardized package structure for Unity Package Manager (UPM).
- Integrated `AppLovinAdsAdapter` implementing `Unity.Core.Services.Ads.IAdsService`.
- Automatic Impression-Level Ad Revenue integration with `Unity.Core.Services.Tracking.TrackingService`.
- Editor window `AppLovinEditorWindow` for Ad Units config, Scoped Registries setup and Android AAR management.
- Added `link.xml` for IL2CPP stripping safety.
